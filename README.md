# Single-Node K3s Security Lab

## Overview

This project demonstrates a lightweight Kubernetes security lab on a single Ubuntu VM using K3s. The lab includes a deployment, service, namespace, network policy, and validation steps.

## Purpose

The goal of this project is to demonstrate:
-Kubernetes fundamentals
-Linux command line comfort
-YAML manidest creation
-Basic Security Control Awareness
-Documentation and GitHub workflow

## Tools Used

-Ubuntu Linux
-K3s
-Kubectl
-Git
-GitHub
-Nginx

## What I Built

-A dedicated namespace for lab resources 
-An Nginx deployment
-A ClusterIP service
-A basic Network Policy
-Evidence and notes documenting the results

## What I learned

I learned how to deploy and manage simple Kubernetes resources on a single Linux VM, how to apply a basic security policy, and how to document the results in a clear and repeatable way
